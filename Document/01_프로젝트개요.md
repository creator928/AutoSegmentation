# AutoSegmentation 프로젝트 개요

## 1. 프로그램 목적
AutoSegmentation은 기존 AutoLabeler를 기반으로 만든 YOLO Segmentation 데이터셋 제작 도구입니다.  
사용자가 이미지에 대해 폴리곤을 직접 그리거나, 브러시로 칠한 영역을 폴리곤으로 변환해 세그멘테이션 라벨을 만들 수 있도록 설계되었습니다.

## 2. 핵심 사용 시나리오
1. 사용자가 작업 폴더를 선택합니다.
2. `classes.txt`가 없으면 클래스 목록을 입력해 생성합니다.
3. 이미지마다 폴리곤 라벨을 생성하거나 수정합니다.
4. 필요하면 마스킹 모드로 특정 영역을 검정색으로 덮어 원본 이미지에 저장합니다.
5. 일정 수량의 검토 완료 데이터가 쌓이면 YOLO Seg 모델 학습을 실행합니다.
6. 학습된 결과로 나머지 이미지에 오토 세그를 수행합니다.
7. 검증 창에서 결과 ONNX 모델의 추론 결과를 확인합니다.

## 3. 주요 기능
- YOLO Seg 형식의 폴리곤 라벨 저장/불러오기
- 클릭 기반 폴리곤 입력
- 브러시 드래그 기반 폴리곤 생성
- 폴리곤 편집
  - 꼭짓점 이동
  - 폴리곤 전체 평행이동
  - 우클릭 삭제
- 원본 이미지 마스킹
  - 클릭 폴리곤 마스킹
  - 브러시 마스킹
  - 저장 전 확인 창 제공
- YOLO Seg 모델 학습
- 학습 결과 기반 오토 세그
- ONNX 기반 검증 창
- 라이트/다크 테마
- 단축키 및 입력 모드 설정

## 4. AutoLabeler와의 차이점
- 바운딩 박스가 아니라 폴리곤 세그멘테이션 라벨을 사용합니다.
- 입력 방식이 `윤곽선 클릭` 과 `브러시 드래그` 중심입니다.
- 오토 라벨이 아니라 오토 세그를 수행합니다.
- 검증도 세그멘테이션 결과를 기준으로 표시합니다.
- `X`는 지우개가 아니라 마스킹 모드로 사용합니다.

## 5. 현재 구현 범위
- 기본 디렉터리/설정 파일 자동 생성
- YOLO Seg 모델 다운로드 확인
- 세그 입력 및 편집 UI
- 작업 상태 관리
- 백그라운드 학습/오토 세그
- EXE 빌드 가능
