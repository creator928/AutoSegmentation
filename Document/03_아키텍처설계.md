# AutoSegmentation 아키텍처 설계

## 1. 구성 개요
- `main.py`
  - 프로그램 실행 진입점
- `autolabeler/app.py`
  - QApplication 초기화
  - 설정/모델 준비
  - 메인 윈도우 실행
- `autolabeler/config.py`
  - 경로 계산
  - 설정 파일 로드/저장
- `autolabeler/models.py`
  - 설정 객체, 폴리곤 라벨 구조 정의
- `autolabeler/services`
  - 작업 폴더 처리
  - 라벨 저장/불러오기
  - worklog 관리
  - 학습/오토 세그 워커
  - 모델 준비
- `autolabeler/ui`
  - 메인 윈도우
  - 세그 캔버스
  - 설정/검증 다이얼로그
  - 스타일시트
- `training_runner.py`
  - Ultralytics YOLO Seg 학습 실행
- `auto_label_runner.py`
  - 결과 PT 모델로 오토 세그 실행
- `validation_runner.py`
  - 결과 ONNX 모델 검증 추론 실행

## 2. 데이터 흐름
1. 프로그램 시작
2. 설정 및 디렉터리 확인
3. YOLO Seg 모델 준비
4. 작업 폴더 선택
5. 클래스 목록 로드 또는 생성
6. 이미지 목록 로드
7. 세그 라벨 편집 또는 마스킹 수행
8. 라벨 저장 및 작업 상태 갱신
9. 학습 실행
10. 오토 세그 실행
11. ONNX 검증

## 3. 캔버스 입력 설계
### 3.1 클릭 입력
- 점을 순서대로 찍어 폴리곤을 구성합니다.
- 우클릭 또는 더블클릭으로 마감합니다.

### 3.2 브러시 입력
- 이미지 좌표 기준 마스크에 브러시 스트로크를 칠합니다.
- 가장 큰 외곽선을 찾아 폴리곤으로 변환합니다.
- 설정된 폴리곤 점 수에 맞춰 단순화합니다.

### 3.3 편집 입력
- 꼭짓점 히트 반경 안이면 점 수정
- 그렇지 않고 폴리곤 내부면 전체 이동
- 우클릭 시 삭제

### 3.4 마스킹 입력
- 클릭 또는 브러시 결과를 폴리곤으로 얻습니다.
- 확인 창 이후 해당 폴리곤 영역을 검정색으로 채웁니다.
- 원본 이미지 파일에 저장합니다.

## 4. 저장 규칙
### 4.1 설정 파일
- 위치: `Data/settings.json`
- 내용:
  - 테마
  - 입력 방식
  - 모델명
  - 단축키
  - 브러시 크기
  - 폴리곤 점 수
  - 학습 옵션

### 4.2 라벨 파일
- 위치: 이미지와 같은 폴더
- 이름: 이미지와 동일 stem, 확장자만 `.txt`
- 형식: YOLO Seg 폴리곤 형식

### 4.3 학습 결과
- 위치: 작업 폴더 `Temp/Result`
- 주요 파일:
  - `result.pt`
  - `result.onnx`
