# AutoSegmentation 실행 가이드

## 1. 권장 환경
- Python 3.10 이상
- Windows 10/11

## 2. 설치
가장 기본적인 설치 방법은 `Code` 디렉터리에서 `requirements.txt` 를 설치하는 것입니다.

```powershell
pip install -r requirements.txt
```

GPU 학습/추론까지 사용하려면 PyTorch를 별도로 설치해야 합니다.

CPU 예시:

```powershell
py -3.10 -m pip install --upgrade torch torchvision torchaudio
```

CUDA 12.8 예시:

```powershell
py -3.10 -m pip install --upgrade --index-url https://download.pytorch.org/whl/cu128 torch torchvision torchaudio
```

## 3. 실행
`Code` 디렉터리에서 아래 명령으로 실행합니다.

```powershell
python main.py
```

이미 빌드된 EXE는 아래 경로에서 직접 실행할 수 있습니다.

- [AutoSegmentation.exe](C:\Users\creat\Desktop\LabelingProject\AutoSegmentation\AutoSegmentation.exe)

## 4. 첫 실행 동작
- `Data`, `Work`, `Document` 등 필요한 경로를 확인합니다.
- 설정 파일이 없으면 기본 설정을 생성합니다.
- 필수 YOLO Seg 모델이 없으면 다운로드 여부를 묻습니다.

## 5. 기본 사용 순서
1. 프로그램 실행
2. 작업 폴더 선택
3. 필요 시 `classes.txt` 생성
4. 클래스 선택
5. `W` 로 그리기 모드 진입
6. `C` 로 클릭/브러시 입력 전환
7. 폴리곤 생성 또는 편집
8. 필요 시 `X` 로 마스킹
9. 검토 완료 데이터가 쌓이면 학습 실행
10. 오토 세그 및 검증 수행

## 6. 주요 단축키
- `` ` `` : 클래스 0 선택
- `1` ~ `9` : 클래스 1 ~ 9 선택
- `W` : 세그 그리기 모드
- `C` : 클릭 입력 / 브러시 입력 전환
- `X` : 마스킹 모드
- `E` : 편집 모드
- `R` : 마지막 폴리곤 삭제
- `A` : 이전 이미지
- `D` : 다음 이미지
- `S` : 화면 맞춤
- `T` : 라이트/다크 테마 전환

## 7. 주의사항
- 마스킹은 원본 이미지를 직접 수정합니다.
- 마스킹 전 항상 확인 창이 표시됩니다.
- 학습과 오토 세그는 시스템 Python 환경과 PyTorch 설치 상태에 영향을 받습니다.
- GPU가 감지되어도 PyTorch의 CUDA 지원이 없으면 실제 실행은 CPU로 전환됩니다.

## 8. EXE 빌드
`Code` 디렉터리에서 아래 명령으로 단일 실행 파일을 빌드할 수 있습니다.

```powershell
python -m PyInstaller --noconfirm --clean --onefile --windowed --exclude-module qt_material --name AutoSegmentation --distpath .. --workpath .\build --specpath . main.py
```

또는 PowerShell 스크립트를 사용할 수 있습니다.

```powershell
.\build_exe.ps1
```
