# AutoSegmentation 의존성 설치 가이드

## 1. 현재 상태
- 기본 의존성 목록은 [requirements.txt](C:\Users\creat\Desktop\LabelingProject\AutoSegmentation\Code\requirements.txt) 에 정리되어 있습니다.
- 현재 프로젝트 루트에는 `install_dependency.bat` 가 없으므로 수동 설치 기준으로 안내합니다.
- EXE 실행은 가능하지만, 학습/오토 세그 기능까지 사용하려면 Python 환경과 PyTorch가 준비되어 있어야 합니다.

## 2. 기본 의존성 설치
`Code` 디렉터리에서 아래 명령을 실행합니다.

```powershell
pip install -r requirements.txt
```

기본 목록:
- `PyQt6`
- `PyInstaller`
- `ultralytics`
- `opencv-python`
- `onnx`
- `onnxscript`

## 3. PyTorch 설치
### 3.1 CPU 환경

```powershell
py -3.10 -m pip install --upgrade torch torchvision torchaudio
```

### 3.2 GPU 환경 예시
CUDA 12.8 기준:

```powershell
py -3.10 -m pip install --upgrade --index-url https://download.pytorch.org/whl/cu128 torch torchvision torchaudio
```

## 4. 설치 확인
### 4.1 PyTorch 확인

```powershell
py -3.10 -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

### 4.2 ONNX 확인

```powershell
py -3.10 -c "import onnx, onnxscript; print(onnx.__version__); print(onnxscript.__version__)"
```

## 5. 빌드 의존성
EXE 빌드에는 `PyInstaller` 가 필요합니다.

빌드 명령:

```powershell
python -m PyInstaller --noconfirm --clean --onefile --windowed --exclude-module qt_material --name AutoSegmentation --distpath .. --workpath .\build --specpath . main.py
```

현재 프로젝트에는 다음 빌드 관련 파일이 있습니다.
- [build_exe.ps1](C:\Users\creat\Desktop\LabelingProject\AutoSegmentation\Code\build_exe.ps1)
- [AutoSegmentation.spec](C:\Users\creat\Desktop\LabelingProject\AutoSegmentation\Code\AutoSegmentation.spec)

## 6. 참고 사항
- `qt_material` 은 실제 앱 기능에 사용하지 않으며, 빌드 시에는 제외하도록 구성되어 있습니다.
- GPU 장치가 있어도 PyTorch CUDA 미지원 환경이면 실제 학습/추론은 CPU로 동작합니다.
- Ultralytics 설정은 프로젝트 내부 `Data/ultralytics` 경로를 사용합니다.
