# AutoSegmentation 요구사항 정의

## 1. 디렉터리 구조
- `AutoSegmentation`
- `AutoSegmentation/Document`
- `AutoSegmentation/Code`
- `AutoSegmentation/Data`
- `AutoSegmentation/Work`

## 2. 기능 요구사항
### 2.1 실행 및 초기화
- 프로그램 시작 시 필수 디렉터리 존재 여부를 확인합니다.
- 필요한 경우 `Data`, `Work`, `Document` 등 기본 경로를 자동 생성합니다.
- 설정 파일이 없으면 기본 설정을 생성합니다.

### 2.2 모델 준비
- 시작 시 선택된 YOLO Seg 모델 존재 여부를 확인합니다.
- 모델이 없으면 다운로드 여부를 사용자에게 묻습니다.
- 기본 모델은 `yolo11n-seg.pt` 입니다.

### 2.3 작업 폴더 처리
- 사용자가 라벨링 작업 대상 폴더를 선택할 수 있어야 합니다.
- 작업 폴더 안에 `classes.txt`가 없으면 입력 창을 통해 생성할 수 있어야 합니다.
- 이미지 목록은 파일명 기준으로 정렬해 보여줘야 합니다.

### 2.4 세그 입력
- `W` 로 그리기 모드에 진입할 수 있어야 합니다.
- `C` 가 다른 기능에 할당되어 있지 않다면 클릭 입력과 브러시 입력을 전환할 수 있어야 합니다.
- 입력 방식은 다음 둘을 지원해야 합니다.
  - 윤곽선 클릭
  - 브러시 드래그
- 브러시 크기를 조절할 수 있어야 합니다.
- 브러시 입력 결과는 설정된 점 수에 맞춰 폴리곤으로 단순화되어야 합니다.

### 2.5 편집
- `E` 로 편집 모드에 진입할 수 있어야 합니다.
- 꼭짓점 근처 클릭 시 꼭짓점 수정
- 폴리곤 내부 클릭 시 폴리곤 전체 평행이동
- 우클릭 시 폴리곤 삭제
- `R` 로 마지막 폴리곤 삭제

### 2.6 마스킹
- `X` 는 마스킹 모드여야 합니다.
- 클릭 폴리곤 입력 또는 브러시 칠하기 결과를 마스크 영역으로 사용할 수 있어야 합니다.
- 저장 전 확인 창을 띄워야 합니다.
- 확인 시 선택 영역을 검정색으로 덮어 원본 이미지에 저장해야 합니다.

### 2.7 라벨 저장
- 라벨은 이미지와 같은 이름의 `.txt` 파일로 저장합니다.
- 형식은 YOLO Seg 형식이어야 합니다.
- 각 라벨은 `class x1 y1 x2 y2 ...` 형식으로 저장합니다.

### 2.8 작업 상태
- 이미지별 작업 상태를 저장하고 다시 불러와야 합니다.
- 사용자 검토 완료, 오토 세그 완료, 미검토 상태를 표시해야 합니다.

### 2.9 학습 및 오토 세그
- 일정 수의 검토 완료 이미지가 있으면 학습을 실행할 수 있어야 합니다.
- 학습 결과로 `result.pt`, `result.onnx` 를 생성해야 합니다.
- 학습 결과 모델로 뒤쪽 이미지에 오토 세그를 수행할 수 있어야 합니다.

### 2.10 검증
- 검증용 이미지에 대해 ONNX 기반 추론 결과를 확인할 수 있어야 합니다.
- 클래스명, confidence, 폴리곤 결과를 함께 확인할 수 있어야 합니다.

## 3. 비기능 요구사항
- 모든 소스는 UTF-8 인코딩을 사용합니다.
- 코드와 주석은 한국어를 기본으로 사용합니다.
- PyQt6 기반 데스크톱 UI를 사용합니다.
- 라이트/다크 테마를 지원합니다.
- EXE 단일 파일 빌드를 지원합니다.
